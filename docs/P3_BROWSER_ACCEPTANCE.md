# Browser evidence acceptance

Dedicated disposable CI uses synthetic Binance HTTP fixtures, real Kafka, migrated PostgreSQL, and a manifest-pinned Parquet snapshot exported from the same ledger. The 24 fixture minutes train/evaluate the statistical model (12 train, 6 validation, 6 test rows). A loopback evidence-only ASGI app serves the ledger and independently pinned report to Next.js. Chromium asserts explicit fixture provenance, bounded ledger rows, model metrics, citation and the deterministic LangGraph trace; then tampers with the disposable report and asserts that the UI removes the forecast rather than fabricating a result. The original report is restored. CI captures screenshots, report and on-failure trace. No production server, external exchange provider or paid model call is used. This covers the fixture evidence journey, not a live exchange, general LLM/RAG, or deployment readiness. Exact-head CI must pass.
