# P3 17-case constrained-agent golden evidence suite

Run from apps/api: PYTHONPATH=. python agent_golden_evaluation.py --output /tmp/agent-golden.json. This creates an original synthetic 32-minute forecast fixture and a separately SHA-256-pinned, immutable local evaluation report, then invokes the ACTUAL LangGraph three-node sequence. One allowed historical request recomputes price-error metrics, cites its pinned artifact, and explicitly denies live-market verification despite malicious words embedded in unused report text. Twelve unsupported or injected prompt examples must be refused before accessing a deliberately missing file. Additional cases cover query-length limits, altered digest, missing file, and a signed artifact containing an invalid boolean model prediction. Tests do not mutate production data. JSON artifact records case outcomes and measured local durations, and is uploaded by the P3 workflow.

This is a deterministic fixed-tool policy test, NOT a test of LLM hallucination, adversarial model instructions, real-time exchange data, provider uptime or payable token costs. Zero LLM tokens means no LLM was called. The tool does not claim to answer arbitrary language questions, make trades or verify live quotes. General conversational RAG evaluation and API hosting remain separate unresolved gates.
