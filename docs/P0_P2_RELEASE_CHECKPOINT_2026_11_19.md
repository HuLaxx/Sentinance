- New offline `forecast_baselines.py` compares last close and fixed trailing mean on one source/symbol's contiguous one-minute OHLCV close history. The independent manifest SHA-256 is required; the existing snapshot verifier checks all three Parquet layers. Every target uses only preceding event-time bars. It rejects gaps, duplicate minute anchors, naive times, and non-finite/nonpositive values. It reports per-target predictions, MAE, RMSE and mean error; no selection by test performance.
- Reproduce with `cd apps/api && python -m pytest tests/unit/test_forecast_baselines.py`. For a real local snapshot install PyArrow and the API dependencies, then run `python -m forecast_baselines /path/to/snapshots/<id> --manifest-sha256 <independently-recorded-hash> --source <source> --symbol <symbol> --warmup 30 --window 5`.
