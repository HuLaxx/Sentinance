# P2 experiment registry and P3 constrained evidence graph

A local content-addressed registry writes canonical evaluation reports exactly once by SHA-256, rejecting changed existing content. Expanding-window evaluation uses disjoint held-out blocks with rolling observed history and train/validation only parameter selection. The registry is not MLflow, a remote registry or a deployed model. The new evidence_agent.py is an explicitly invoked offline LangGraph workflow: retrieve a separately pinned report, recompute supported error metrics, produce a structured citation and trace. It exposes no trading tool, no LLM, no provider API, no arbitrary query-controlled path, and no arbitrary artifact text enters the response. Only the exact query "compare forecasts" is supported. Unsupported prompts are refused before reading. This demonstrates bounded deterministic agent orchestration, not a production conversational RAG assistant or validated LLM quality. The existing conversational agent remains separate.

Use from apps/api: python evidence_agent.py /operator/report.json --sha256 INDEPENDENT_HASH --query "compare forecasts". The report must come from the snapshot workflow with a manifest hash and symbol. Outputs contain measured local step durations; they do not promise a latency SLA. No live or paid API is used. Report-only comparison can be reproduced from fixture data, with no permission to trade or deploy.
